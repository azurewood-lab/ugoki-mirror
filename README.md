# うごきミラー v0.2.0（試用版）

運動する → 自分の動きを見る → 次の試技で確かめるための、Chrome向けWebアプリです。

- **自動で見る**：3・5・10秒あとに映像を表示。毎回の撮影操作は不要です。
- **押して見る**：運動のあとに「ゆっくり見る」で、押す前の直前3・5・10秒を見返します。「もう一度」で同じ区間、「つぎへ」で映像を消してカメラを再開します。
- 再生は1・0.5倍、先生の設定から0.25倍も選択できます。停止・再開、再生位置、カメラ切替、左右反転、全画面に対応。
- アカウント・インストール不要、無料・広告なし。音声収録・映像送信・保存・共有・アクセス解析SDKはありません。
- 映像は端末のメモリ内で処理。保持バッファは10.8秒・画像計算値64MiB以内（処理中の画像・入力映像・Canvas等は別）。標準480×270・10コマ/秒、軽量320×180・8コマ/秒を目標に取得し、撮れていない瞬間の補間はしません。
- 見返し中はカメラ停止。静止画・見返す映像は最長60秒、カメラ連続利用は15分で自動終了。「おわる」・タブ移動・ページ離脱でカメラ停止と映像解放。ブラウザー停止中の厳密な実時間処理は保証しません。
- 配信サービス側のアクセスログ（IPアドレス等）は、映像を送信しないことと別です。
- 学校端末での動作・実際の遅延・長時間の安定性・学校での利用可否は未確認です。学校の経路で、URLへのアクセスとカメラ利用を別々に確認してください。
- 撮影場所・画角・映らずに参加する方法は、アプリ内の「使い方」を授業者と確認してください。

HTML/CSS/JavaScriptだけで動作し、外部ライブラリ・API・ビルド工程はありません。映像は共通の上限付き画像バッファを使い、取得時刻に基づいて遅延・スロー表示します。

ローカル開発は `python3 -m http.server 8765 --bind 127.0.0.1` で起動し `http://127.0.0.1:8765/` を開きます。公開時のカメラ起動にはHTTPSが必要です。
