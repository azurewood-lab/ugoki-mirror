# 体育リプレイ v0.3.0（試用版）

運動する → 自分の動きを見る → 次の動きで確かめるためのWebアプリです。

- **おくれて再生**：動いたあと、自動で映る。5・10・15秒から選択、最初は10秒。
- **スロー再生**：動いたあと「直前10秒を見る」などのボタンで、押す前の区間を見返す。「もう一度」で同じ動き、「つぎへ」で映像を消してカメラ再開。
- 時間・画質・左右反転を常に表示。時間・画質の変更は古い映像を消し、カメラ使用中なら取り込みを再開。再生速度1・0.5・0.25倍、再生位置、一時停止、カメラ切替に対応。
- 「映像を大きく」は映像と小さな操作欄だけを表示。全画面APIが使えないときはページ内で拡大し、「もとの大きさ」で戻る。
- アカウント・インストール不要、無料・広告なし。音声収録・映像送信・保存・共有・アクセス解析SDKなし。
- 映像は端末のメモリ内だけで処理。保持は選択秒数＋0.8秒（最大15.8秒）、画像計算値64MiB以内。処理中の画像・入力映像・Canvas等は別。標準480×270で毎秒10コマ、15秒設定では毎秒8コマ、低め320×180で毎秒8コマを目標に取得。撮れていない瞬間の補間はしない。
- 見返し中・一時停止中はカメラ停止、映像は最長60秒。連続利用は15分で終了。「おわる」・タブ移動・ページ離脱でカメラ停止と映像解放。ブラウザー停止中の厳密な実時間処理は保証しない。
- 配信サービス側のアクセスログ（IPアドレス等）は、映像を送信しないことと別。
- 学校端末の動作・実際の遅延・長時間の安定性・学校での利用可否は未確認。URLへのアクセスとカメラ利用は学校の経路で別々に確認。
- 安全な撮影場所・全身の画角・映らずに参加する方法は授業者と確認。

HTML/CSS/JavaScriptだけで動作し、外部ライブラリ・API・ビルド工程はありません。取得時刻の付いた画像を上限付きバッファで保持し、遅延・スロー表示に共用します。

ローカルはこのディレクトリで `python3 -m http.server 8765 --bind 127.0.0.1` を起動し、`http://127.0.0.1:8765/` を開きます。公開時のカメラ起動にはHTTPSが必要です。
